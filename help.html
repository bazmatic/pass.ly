Pass Tracker — Help

Overview

Pass Tracker records the outcome of every pass during a match in real time. Tap the big buttons as each pass happens — the app tracks accuracy, streaks, and timing so you can review performance after the game.

Starting a Match

Tap 1st to begin the first half. The match clock starts immediately. All pass events are timestamped from this moment.

▶ 1st 00:00
▶ 2nd

At half time, tap 2nd. You'll be asked to confirm — once the second half starts, first half data is locked and can't be changed. The clock continues from where it left off.

▶ 1st 34:12
▶ 2nd 00:00

Recording Passes

✓ Complete — pass was received successfully. Increments the streak counter.
✗ Failed — pass was intercepted or missed. Resets the streak to zero.
↺ Streak Reset Lost possession — the team lost the ball without a direct pass failure (e.g. a tackle, the ball went out, or a goal was scored). Resets the streak but does not count as a failed pass, so it doesn't affect accuracy.
The streak counts consecutive completed passes. It resets on any fail or possession loss. The best streak (⭐) records the highest run achieved in the session.

Utility Buttons

↩ Undo — removes the last recorded event. Greyed out when there's nothing to undo.
↗ Share — sends a summary of current stats via the system share sheet. On desktop it copies the text to the clipboard instead.
⬇ Export — downloads the full session as a JSON file named pass-tracker-YYYY-MM-DD.json. This file can be loaded into the stats viewer for charts and analysis.
⟳ Reset — clears all data and restarts from zero. A confirmation prompt appears first. This cannot be undone.

Viewing Stats

After the match, tap ⬇ Export to save the JSON file, then open the Stats Viewer and drop the file in to see accuracy charts, a per-pass timeline, and quarter breakdowns.

Keep the app open during the match — closing or refreshing the page will lose unsaved data. Export before you close.
